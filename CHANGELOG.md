# Changelog

## 2.0.2 — 2026-11-15

- English defaults and persistent Brazilian Portuguese option.
- Immediate hover/focus help without modal dialogs; tooltip animation disabled.
- NSIS per-user installer with both manuals, shortcuts, attribution and uninstaller.
- Installed data separated from program files and preserved on uninstall.
- Native Mac builder prepared; Mac binaries and notarization remain pending.
- 53 regression tests; three EXE rounds and three installation cycles verified.

## 2.0.1 — 2026-11-15

- Single-file Windows EXE includes Python and SVG backend.
- Readable light/dark palettes, selections, headings, plot and diary controls.
- Manual plot layout controls work; F0 means preserve pauses and require adequate voiced support.
- Full results-table PNG; original frames/doses preserved.
- Original code by Pasquale Bottalico and VoxDose development by Tiago Lima Bicalho Cruz, UFMG, credited together.

## 2.0.0 — 2026-11-15

- Modular application, tabbed PySide6 interface, block processing, comparisons and descriptive diary.
- Explicit calibration, units and numerical corrections documented in `docs/METHODS.md`.
- Bilingual manuals, synthetic examples and independent ground-truth checks (142/144 criteria, with two documented low-SNR F0 limitations).

The former GitHub snapshot (1.0.2 metadata) is preserved under `legacy/v1`, based on commit `aaf805af5e7474db6986b59a68de603e5e3a7a0d`. Its manuscript and bibliography remain unchanged at the root.
